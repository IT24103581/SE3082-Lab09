# SE3082 Lab 09: Introduction to CUDA

**Module:** SE3082 – Parallel Computing  
**Lab:** 09 – Introduction to CUDA (Google Colab Edition)

## Description

This lab introduces GPU programming using CUDA in Google Colab. It covers CUDA kernel execution, threads and blocks, memory management, vector operations, and matrix operations.

## Exercises

1. Hello GPU
2. Adding Two Numbers
3. Vector Addition Using Multiple Blocks
4. Vector Addition Using Multiple Threads
5. Vector Multiplication
6. Matrix Element-wise Multiplication

## Tools Used

- Google Colab
- NVIDIA CUDA Toolkit
- CUDA C/C++

## How to Run

1. Open the `.ipynb` notebook in [Google Colab](https://colab.research.google.com/).
2. Enable a GPU runtime if available.
3. Run the notebook cells in order.
4. Review the output and verification results for each exercise.

## Verification

The vector and matrix operations include verification checks to compare GPU results with expected CPU results.
